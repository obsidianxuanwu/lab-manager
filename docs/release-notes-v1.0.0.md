# v1.0.0 · 实验室管理系统 首个正式版

> 打包日期：2026-10-27
> 发布页：<https://github.com/obsidianxuanwu/lab-manager/releases/tag/v1.0.0>

单文件网页应用，双击即用，不联网、不装软件。

## 这个版本能做什么

- **实验室列表**：卡片总览，每间实验室的状态、容量、设备概况一目了然
- **日程总表**：按周次展开全部实验室的占用情况，找空房用
- **查空房**：选定周次和节次，直接筛出没课的实验室
- **课表导入**：支持 `.xls` / `.xlsx`，无需另存格式；可单间导入，也可一次批量导入
- **设备配置**：硬件、软件、系统分项登记，随时增删改
- **报修登记**：记录问题、跟进进度，一键导出 Excel 报表
- **备份恢复**：导出 `.json` 备份，换电脑时导入即可

## 下载与使用

1. 从 [Releases](https://github.com/obsidianxuanwu/lab-manager/releases/tag/v1.0.0) 下载 `实验室管理系统-2026-10-27.zip`
2. **解压到桌面**（不要在微信/QQ 的文件接收目录里直接打开，那里会被系统清理）
3. 双击 `实验室管理.html`，用 Chrome 或 Edge 打开
4. 首次使用：先填「本学期第一周日期」，再导入课表文件

详细步骤见压缩包内的 `使用说明.md`，那份文档是写给不熟悉电脑操作的人的。

## 注意事项

- 数据保存在浏览器本地（localStorage），与「文件所在位置 + 浏览器」绑定
- **移动文件位置或更换浏览器前，请先导出备份**，否则会看到空白
- 建议每周备份一次，备份文件放到网盘或移动硬盘
- 当前为单机单人版本，没有账户体系，多人同时使用需改造为服务端版本
