# 实验室管理系统 · 一页纸速查

> 给**已经会用**的人。第一次用请翻 [使用说明.md](../使用说明.md)。
> 建议打印出来贴在办公桌旁。

---

## 三条铁律

1. **整个文件夹放桌面，放好就别挪** —— 挪了数据就"消失"（其实是换了地方存）
2. **别用无痕/隐私模式打开** —— 关了窗口数据就没了
3. **每周导出一次备份** —— 清理软件、重装系统都能扛过去

---

## 查哪间实验室空着

`日程总表` → 周次 `−` `+` 调到要看的周 → 点「周一…周日」→ 看表格

- **灰底写"空"** = 可借
- **粉色格** = 有课，点开看课程详情
- 借之前确认一下没被临时占用（开会、考试、检修）

## 导入课表

实验室卡片 → `导入课表` → 点虚线框 → 选 `.xls` / `.xlsx` → 展开核对 → `确认导入`

- 可一次选多个文件；同一实验室重复导入会**覆盖**
- 程序靠课表标题里的房间号认实验室，标题里没房间号会认不出来

## 登记报修

实验室卡片 → `报修记录` → `＋ 添加报修记录` → 填机位号（如 `12号机`）→ 勾问题 → `保存`

- 6 个选项可**多选**；勾「其他」必须写清楚
- 进度就点记录里那两个勾：`已申报` / `已维修完毕`

## 改配置

`资产配置` → 该行最右 `改` → 保存
新增一行点 `＋ 添加软件`（或 `＋ 添加一行`）

- 右上角勾 `编辑模式` 可直接点表格改，不勾是只读防手滑
- 改实验室名称：拉到底 `实验室设置` → 改名称/编号

## 备份 / 恢复

| 做什么 | 怎么点 |
|---|---|
| 备份 | 主页 `导出备份` → `下载为文件` → 存到网盘或U盘 |
| 恢复 | 主页 `导入备份` → 选 `.json` → `导入并覆盖` |

## 大节对照

| 大节 | 小课次 |
|---|---|
| 一 | `01-02` |
| 二 | `03-04` |
| 三 | `06-07` |
| 四 | `08-09` |
| 五 | `10-11` |

> 中间**没有 `05`**，这是学校课表的原始编号，程序照原样保留。

## 出问题先查这三条

| 现象 | 先看这里 |
|---|---|
| 双击打不开 / 显示一堆代码 | 右键 → `打开方式` → 选 Edge 或 Chrome |
| 内容不对、数据像没了 | 是不是挪了文件夹？**放回原位**再开 |
| 日期不显示、周次没反应 | 填 `本学期第一周周一`（如 `2026-09-01`） |
| 某间实验室全天空 | 它还没导课表，卡片上会有橙色 `还没导课表` |
