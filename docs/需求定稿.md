## 零、总原则（贯穿全部，最先记）

1. **数据原样保留。** 表格里写什么就存什么、显示什么。
   `800GB` 就是 `800GB`，`SQLSever` 就是 `SQLSever`，`2017` 就是 `2017`，`2023.2..1` 就是 `2023.2..1`。
   **不纠正、不规范、不合并、不换算、不四舍五入、不补全。**
   （曾犯过的错：看到疑似笔误就想去"提醒核对"。这不是校对工作，是忠实搬运。）
2. **不做需求之外的东西。** 不加设备序列号台账、不加保修到期计算、不加联网、不加多用户、不加权限。
3. **不做猜测。** 不确定的地方宁可暴露出来提醒，也不要默默按某个假设处理。
4. **遇到读不懂的数据要报错，不要静默丢弃。**

## 二、模块一：实验室资产管理

### 2.1 实验室

- **预置 203、330**（数据来自 `10.13副本软件学院实验室配置清单6.11.1 - 副本.xlsx` 的两个工作表）
- **能新增 / 编辑 / 删除实验室**，包括改名字（其余 6 个的名字由老师自己填）
- 实验室标识：**编号**（工作表名，如 `203`）+ **名称**（如 `智能科学实验室`）

### 2.2 每个实验室一份配置表单（不是逐台电脑）

**一个实验室 = 一张表单**，实验室里所有电脑配置相同，**没有"逐台电脑"这一层**。

三段结构（与配置清单一致）：

| 段 | 字段 |
|---|---|
| **一、硬件配置** | 项目 / 配置 / 采购年份 / 保修状态 / 数量 |
| **二、系统环境** | 项目 / 版本·配置 |
| **三、软件清单** | 类别 / 软件名称 / 版本 / 备注 |

约定：

- 采购年份、保修状态**按行记**（不整块共用）——因为 330 的硬盘年份确实和其他行不同
- **数量只有一个数字**，只写在第一行（`64台` / `69`）
- 三段**都能编辑**：增行、删行、改内容
- **备注列保留**，空着就空着，位置留着以后能填
- 平时是只读展示，需要时进编辑模式

### 2.3 报修记录（挂在实验室下面）

每个实验室**单独一份报修单**（这是它不需要带实验室编号的原因）。

每条记录：

| 字段 | 说明 |
|---|---|
| 报修时间 | |
| 电脑编号 | **不带实验室**，如 `12号机` |
| 报修问题 | |
| 已申报 | 状态一 |
| 已维修完毕 | 状态二，**与"已申报"独立** |

流程（已确认）：

```
学生发现问题 → 报给老师 → 老师录入        → 未申报
                        → 已报给维修方     → 已申报（未修完）
                        → 修好             → 已维修完毕
```

**报修单可编辑**（老师自己录入，所以要能改）。

### 2.4 两处提醒，位置不同

| 提醒 | 位置 | 条件 | 要求 |
|---|---|---|---|
| **未申报** | **主页**小字公告栏 | 有"未申报"的记录 | **必须写明是哪一条，并带上实验室编号**<br>例：`203实验室：12号机 报修未申报` |
| **未维修完毕** | **对应实验室主页** | 该实验室有"未修完"的记录 | 提醒"注意检查" |

## 三、模块二：日程表 & 状态展示

### 3.1 数据来源

- 每个实验室有**学校发的课程表**（纸质贴在门上，也有对应电子文件）
- 电子文件**暂时还没有**，老师之后提供
- **纸质照片不能用于自动识别**（字段太多，错一个就误导老师）。照片只作录入底稿。

### 3.2 学校课表的结构（已确认）

**表头**：学年学期（如 `2026-2027-1`）、教室、座位数、打印日期

**网格**：

| 维度 | 内容 |
|---|---|
| 横列 | 星期一 ~ 星期日（**7 天，含周末**） |
| 纵列 | **第一 ~ 第五大节**（**5 个大节**） |
| 每格 | 可能有**多门课**，每门课 4 行：课程名 / 班级 / 教师 / 周次+节次 |

**每门课的例子**：

```
面向对象程序设计 I (Java)
26数据4班
宋杰鹏
6-11, 13, 15 周[01-02节]
```

### 3.3 小课次编号（重要）

全天小课次**连续编号**，**建到 12**（晚上不确定有没有课，留够位置）：

| 大节 | 小课次 |
|---|---|
| 第一大节 | `[01-02]` |
| 第二大节 | `[03-04]` |
| 第三大节 | `[06-07]` |
| 第四大节 | `[08-09]` |
| 第五大节 | `[10-11]` |
| 预留 | `[12]` 及以后 |

- **`[05]` 空着不用，也不许改成 `[06]`→`[05]`。编号是对的，原样保留。**
- **8 个实验室作息时间一致**（已确认）

### 3.4 排版陷阱（必须处理）

学校课表**因为列宽不够，会把一句话拆成两行**。例如：

```
实际内容：  6, 8-12, 14, 16 周[03-04节]
屏幕上被拆成：
   6, 8-12, 14, 16        ← 第一行
   周[03-04节]            ← 第二行
```

**程序必须能把被拆开的接回去**：看到「一行是周次数字」+「下一行是 `周[xx-xx节]`」→ 合并为一条。

否则每个格子会被读成**两条记录**。

### 3.5 三个视图

| 视图 | 说明 |
|---|---|
| **主页对比表（核心）** | **5 大节（行）× 8 个实验室（列）**，可切换**周次**和**周几**；格内显示该实验室该大节上的课（可能多门，全列出）。列的**左右顺序老师可自由调整** |
| **单实验室课表** | 复现学校那张纸的样子：星期一~日 × 五大节，内容原样 |
| **日期换算** | 老师填「本学期第一周周一是几月几号」→ 之后所有「第几周周几」自动对应日期。默认跳到**今天**（读本机系统时间即可，**不需要任何插件**），也允许手动选 |

### 3.6 周次必须可查询（已确认做法）

周次**不能只存字符串**，否则"表随周次变化"就实现不了。

| 存法 | 结果 |
|---|---|
| 只存 `"6-11, 13, 15周[01-02节]"` | 能显示，**但选第12周时判断不了上不上课** |
| **拆开存**：周次=[6,7,8,9,10,11,13,15]，小节=[1,2] | 能显示，**且能按周次筛选** ✅ |

**已确认采用拆开存，显示时拼回去**（显示效果和原表一致）。

**筛选逻辑**：老师选「第 N 周 周X」→ 对每个实验室逐个问：
"这门课的周次清单里有没有 N？星期对不对？" → 有则标注，无则留空。

### 3.7 读不懂的周次要暴露

若某格写的是人话（如 `见教务系统`、`另行通知`、`不定期`）而不是周次：

- **不猜、不当成"没课"**
- **明确列出来提醒老师**："这条我看不懂周次"

理由：静默漏掉 = 老师以为那间实验室空着 → 白跑一趟。

### 3.8 暂不做（明确排除）

- ❌ 查"某个班在哪上课"（只从实验室角度出发）
- ❌ 多用户/权限（就一位老师用）

## 四、技术结论（已验证，不是猜测）

### 4.1 读 xlsx：不需要外部组件

**已实测通过**（用老师自己的配置文件验证）：

| 检查项 | 结果 |
|---|---|
| 浏览器自带解压能力 | ✅ 支持 |
| 读 xlsx（15.7 KB） | ✅ 成功 |
| 解析耗时 | **< 1 毫秒** |
| 需要外部组件吗 | **不需要** |

方法：xlsx 本质是 ZIP + XML。用浏览器自带 `DecompressionStream('deflate-raw')` 解压，自己解析 XML。

**好处**：程序体积小（不用背 800KB 的库），符合"都在一个文件夹里不外置"的要求。

### 4.2 合并单元格已验证正确

配置文件用大量合并单元格表达"同类别"（如 `A17:A20` = "开发工具"）。
实测：**能把左上角的值正确填满整个合并区域**，所以类别能正确继承到每一行。

### 4.3 数据落地方式

- 单机、一个 HTML 文件、双击即用
- 数据存本机浏览器（localStorage）+ **导出/导入备份**（换电脑、重装时要用）
- 允许**导入 Excel** 和**界面手输**两条路（模块一、模块二都是）
